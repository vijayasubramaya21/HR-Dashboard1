# 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an **HR Analytics Dashboard** created using **Microsoft Power BI** to analyze employee data and provide meaningful insights into workforce demographics, employee performance, promotion status, job levels, satisfaction, overtime, and employee retention.

The dashboard helps HR teams understand workforce patterns and identify employees who may require promotion or further attention.

---

## 🎯 Project Objective

The main objectives of this project are to:

- Analyze the overall employee workforce.
- Understand the gender distribution of employees.
- Identify employees due for promotion.
- Analyze employee service years.
- Understand employee distribution across different job levels.
- Analyze employee distance status.
- Monitor employee overtime.
- Analyze job satisfaction levels.
- Identify employees due for promotion or potential retrenchment.
- Provide department-wise and job-role-wise HR insights.
